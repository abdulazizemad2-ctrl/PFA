# اختبار تفاعلي — مبادئ الإسعافات الأولية (MED)

اختبار إلكتروني من **ملخصات أبو عماد** يضم 68 سؤالاً (42 من التجميعات و26 جديداً) للمحاضرات الثلاث للاختبار الدوري الأول:

1. مفهوم الإسعافات الأولية
2. الاختناق والإنعاش القلبي الرئوي
3. التسمم

## أنواع الاختبار
- اختبار شامل بترتيب الملخص
- اختبار سريع: 20 سؤالاً في 15 دقيقة
- اختبار حسب المحاضرة
- مراجعة الأخطاء والأسئلة المعلّمة (تُحفظ في متصفحك)
- نتيجة لكل محاضرة

بجهود الطلاب وقنوات مجتمع الحقوق، وتنسيق ملخصات أبو عماد.
قناة ملخصات أبو عماد الرسمية: https://t.me/molaksat_aboemad
